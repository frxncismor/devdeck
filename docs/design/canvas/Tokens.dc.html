Color

Semantic tokens · same names in both themes · switch with class="dd dark" / "dd light" on the app root

Every text pairing used in the app passes WCAG AA (4.5:1), including 11.5px meta text in --text-subtle on --surface. Danger is always paired with an icon and a label, never color alone.
